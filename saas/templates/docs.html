Documentación de la API

Base URL: {{ api }}. Todas las llamadas llevan tu token en la cabecera Authorization: Bearer bpv_…. Úsalo solo desde tu servidor.

1. Conecta tu Binance (una sola vez)

En Binance crea una API key con solo «Enable Reading» (sin trading, retiros ni transferencias; si la restringes por IP, añade la IP del servidor de la API). Regístrala desde Mi cuenta o con la API:

curl -X PUT {{ api }}/v1/me/binance-credentials \
  -H "Authorization: Bearer bpv_TU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"apiKey": "TU_API_KEY", "apiSecret": "TU_SECRET"}'

Responde 200 si se aceptó, o 422 con el motivo si la key no es de solo lectura o no puede leer tu historial de Binance Pay.

2. Verifica un pago

Tu cliente te paga por Binance Pay y te da el ID de orden que le muestra Binance. Tu servidor lo verifica:

curl -X POST {{ api }}/v1/payments/verify \
  -H "Authorization: Bearer bpv_TU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"paymentCode": "457883830937640960",
       "expectedAmount": "4.99",
       "asset": "USDT",
       "orderReference": "pedido-123"}'
CampoDescripción
paymentCodeID de orden de Binance Pay. Se compara exacto.
expectedAmountImporte esperado como texto ("4.99"), nunca como número decimal.
assetMoneda, por defecto USDT.
orderReferenceId del pedido en tu sistema. Reintentar con el mismo es seguro (respuesta idempotente).
maxAgeMinutesOpcional: antigüedad máxima aceptada del pago.

Respuesta:

{
  "verified": true,
  "status": "VERIFIED",
  "paymentCode": "457883830937640960",
  "expectedAmount": "4.99",
  "receivedAmount": "4.99",
  "asset": "USDT",
  "receivedAt": "2026-10-07T12:00:00Z",
  "orderReference": "pedido-123",
  "retryable": false
}

3. Cómo decidir

  • verified: true → entrega el producto.
  • retryable: true → reintenta en 5–10 segundos (un pago recién hecho tarda unos segundos en aparecer).
  • Cualquier otro caso → rechaza y muestra el motivo.
statusSignificado
VERIFIEDPago correcto y reservado para ese pedido.
NOT_FOUNDAún no aparece, o el ID no existe / es demasiado antiguo.
AMOUNT_MISMATCHEl importe no coincide (ver receivedAmount).
ASSET_MISMATCHSe pagó en otra moneda.
ALREADY_CLAIMEDEse pago ya se usó en otro pedido.
EXPIRED_PAYMENTEl pago es más antiguo de lo permitido.
PENDING_SYNC / BINANCE_API_UNAVAILABLETemporal: reintenta.
BINANCE_NOT_CONFIGUREDFalta registrar tu API key de Binance.

Errores HTTP: 401 token inválido o suscripción vencida · 422 datos inválidos · 429 demasiadas peticiones.

Ejemplo en Python

import httpx

r = httpx.post(
    "{{ api }}/v1/payments/verify",
    headers={"Authorization": "Bearer bpv_TU_TOKEN"},
    json={"paymentCode": order_id, "expectedAmount": "4.99",
          "asset": "USDT", "orderReference": pedido_id},
    timeout=60,
)
data = r.json()
if data["verified"]:
    activar_plan(pedido_id)
elif data["retryable"]:
    reintentar_mas_tarde()
else:
    rechazar(data["status"])

Otros endpoints

  • GET /v1/me — quién eres (comprobar el token).
  • GET /v1/me/binance-credentials — estado de tu API key de Binance.
  • DELETE /v1/me/binance-credentials — borrar tu API key.
  • POST /v1/me/binance/sync — importar ahora tus últimos pagos recibidos.
